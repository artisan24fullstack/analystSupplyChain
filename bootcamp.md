# Bootcamp

## Bootcamp - Data Analysis

- Start your career in data analysis
- As a data analysis professional, what are your responsibilities?

### Typical missions you will be able to carry out:

```
* Identify and analyze user needs to facilitate strategic decision-making.
* Implement simple and complex SQL queries to interrogate a database.
* Load data from various sources into a database and clean it to prepare for your analyses.
* Synthesize data by creating actionable dashboards using data visualization tools.
```

##### You will master the most in-demand technologies and methodologies: 
`SQL`
`PowerBI`
`Excel`
`Data Quality`
`GDPR`

## Bootcamp - SQL and Database 

- Unlock New Opportunities in Data Analysis: 
- Specialize in Databases and SQL Queries

### What You Will Learn

```
* Learn to validate and interpret client requirements effectively, 
ensuring your database solutions align with business objectives
* Master the use of data dictionaries to standardize data definitions 
and improve database design consistency.
* Develop skills to create efficient relational schemas, 
optimizing data organization and relationships.
* Build databases that adhere to industry standards, 
ensuring data integrity and reducing redundancy.
* Gain practical experience in importing data from CSV files into your database, 
a crucial skill for data integration.
* Develop proficiency in writing both simple and 
advanced SQL queries to extract valuable insights from your data.
```

`CSV`
