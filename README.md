# Become a Supply Chain Analyst

- Leverage and interpret supply chain data.

## As a Supply Chain Analyst, what are your responsibilities?

```
- Identify and gather data needs from Supply Chain stakeholders to provide analytical insights.
- Clean and combine data from various sources using Excel or Python to prepare for analysis.
- Write advanced SQL scripts and set up queries to process large volumes of data.
- Create simulation tools with Python
- Write optimization studies to improve Supply Chain performance.
- Synthesize supply chain-related data by creating dashboards
- Train operational stakeholders on Data Visualization tools.
```
