# Project Supply Chain

```
The Supply Chain (the management of flows to deliver to an end customer) 
is a global network for delivering products and services from raw materials to end customers.

The Supply Chain is not limited to logistics, transportation, or procurement.
```

## Start your Supply Chain Analyst training
- Set yourself up for success in your journey: envision your training, define your schedule, and familiarize yourself with the essential tools for learning.

## Improve warehouse activity monitoring for a company
- Conduct your first data analysis using Excel to improve inventory management for a fast-food chain.

## Use Excel to optimize a company's delivery routes
- Help your manager collect, consolidate, and prepare Supply Chain data to reduce transportation costs and the CO2 impact of your company.

## Optimize product return flows for a factory
- Create a dashboard that classifies items according to their frequency of return to the factory, in order to avoid excess flow costs to inventory.

## Manipulate a database with SQL to analyze return activity
- Identify the causes of parcel returns for an e-commerce company. Then propose solutions to limit certain returns and add value to others.

## Optimize management & clean up a store's inventory data
- Help a retail manager clean up their data and resolve inconsistencies.

## Create a simulation tool with Excel to forecast your orders
- In a large DIY retail chain, your manager asks you to determine optimal stock levels by building a planning aid tool.

## Optimize the capacity of a production line
- Practice writing SQL queries and creating visualizations with a dashboarding tool to improve the performance of a production chain.

## Analyze annual sales peaks to better manage activity variations
- Help a company better plan its activity by analyzing seasonality with Excel or Python.

## Model sales for a group of stores using Python
- Using time series analysis, advise the general manager of a pharmacy chain on stock distribution among the brand's stores.
